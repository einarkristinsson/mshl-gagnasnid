# Gagnaveitur

Ein síða á hverja gagnaveitu: endapunktur, umfang, reitir sem berast,
kortlagning í leitarvísinn, þekkt frávik og hvernig brugðist er við þeim.

Allar tölur eru mældar á raungögnum og dagsettar.

## Hvað hver síða svarar

1. **Endapunktur** — hvar gögnin eru sótt og hvað þjónninn styður
2. **Umfang** — hve mikið, af hvaða tegundum, mælt hvenær
3. **Reitir sem berast** — hvað er raunverulega í gögnunum og hve víða
4. **Kortlagning í Leitir** — hvaða DC-reitur verður að hvaða leitarsviði
5. **Þekkt frávik** — hvað mælist öðruvísi en staðallinn segir
6. **Hvað við gerum við þau** — hvernig okkar hlið bregst við

Frávikin eru skráð hlutlægt: hvað mælist og hvaða afleiðingu það hefur.
Gagnaeigandi á að geta lesið sína eigin síðu án þess að finnast hann kærður.
